## Projects

### 1. Personal Developer Portfolio

A responsive personal portfolio website showcasing my introduction, skills, projects and contact information.

**Features:**

- About, Skills, Projects and Contact sections
- Dark and light theme toggle
- Resume section
- Contact links

**Technologies:** HTML5, CSS3 and JavaScript

**Live Website:** https://fathimalubabanailabathool-blip.github.io/Fathima-Portfolio/

**Source Code:** [Fathima-Portfolio](./Fathima-Portfolio/)

### 2. Dynamic Task Manager

A task management application that helps users organise daily activities and track their progress.

**Features:**
- Add, edit and delete tasks
- Work, Personal and Study categories
- Due dates
- Complete and reactivate tasks
- All, Active and Completed filters
- Local storage for saving tasks
- Responsive design

**Technologies:** HTML5, CSS3 and JavaScript

**Live Website:** https://fathimalubabanailabathool-blip.github.io/Datheon_Full_Stack_Web_Development_Internship/

**Source Code:** Available in the repository root (`index.html`, `style.css` and `script.js`).

### 3. Weather Forecast App

A responsive weather application that displays current weather conditions and a five-day forecast for searched cities.

**Features:**
- Search weather by city name
- Current temperature and weather conditions
- Humidity, wind speed and atmospheric pressure
- Five-day weather forecast
- Dynamic weather icons
- Weather-based background gradients
- Daytime and nighttime background changes
- Loading indicator and error handling
- Responsive design

**Technologies:** HTML5, CSS3, JavaScript, Fetch API, Async/Await and OpenWeatherMap API

**Source Code:** [Weather-Forecast-App](./Weather-Forecast-App/)

### 4. SN Traders – E-Commerce Product Catalog

An interactive and responsive online shopping website where users can browse products, search, filter categories and manage a shopping cart.

**Features:**
- Dynamic product catalog using FakeStoreAPI
- Product search functionality
- Category-based filtering
- Product images, prices and ratings
- Indian Rupee (INR) price display
- Add and remove products from cart
- Increase and decrease product quantities
- Automatic cart total calculation
- Shopping cart saved using localStorage
- Slide-out shopping cart drawer
- Simulated checkout and order confirmation
- Responsive design

**Technologies:** HTML5, CSS3, JavaScript, FakeStoreAPI, Fetch API, Async/Await and localStorage

**Source Code:** [SN-Traders](./SN-Traders/)
